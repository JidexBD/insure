# Insure website Design 
## Insure is an insurance company that takes care of life and property
    The project includes responsive UI components,
    a mobile-first navigation system, a right-side sliding sidebar, and clean
    semantic HTML/CSS architecture

## Features
    Fully responsive navigation bar
    Modern layout using custom variables (CSS vars)
    Scalable component-based structure
    Optimized assets and typography
    
## Tech Stack
     HTML5 (semantic structuring)
    CSS3 (Flexbox, Custom Properties, Media Queries)
    JS (for the nav and footer component)


## 📂 Project Structure

```text
insure/
│
├── css/
│   ├── homepage.css    # Homepage-specific styles
│   └── style.css       # General website styles
│
├── images/             # Project images and visual assets
│
├── index.html          # Main HTML page
├── script.js           # JavaScript functionality
└── README.md           # Project documentation
```
